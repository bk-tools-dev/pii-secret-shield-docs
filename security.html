Security & Data Residency Statement

App: PII & Secret Shield for Jira (by BK-Tools)

1. Runs on Atlassian Architecture

  • Compute: 100% Atlassian Forge serverless runtime (nodejs22.x).
  • Storage: 100% Atlassian Forge KVS (storage:app), isolated per customer installation.
  • External Network Egress: None (no external.fetch or Forge Remote permissions).
  • External AI / LLMs: None. All detection is 100% deterministic (ISO 7064 Mod-97 IBAN validation, Luhn credit card checksums, bounded high-precision secret rules).

2. Least-Privilege Scopes

  • read:jira-work – scan issue summaries, descriptions, and comments.
  • write:jira-work – replace detected PII/secrets in-place with [REDACTED:CATEGORY] and strip sensitive mailto: links when redaction is triggered.
  • storage:app – store admin settings and masked audit metadata inside Atlassian Forge KVS.

3. Safe Audit Logging

Raw PII and API secrets are never written to console logs or Forge KVS. Only masked representations (e.g. DE89****3000) and category counts are shown or logged.

4. Vulnerability Reporting

Report security issues directly to BK-Tools at b.kuertuel@gmail.com.
